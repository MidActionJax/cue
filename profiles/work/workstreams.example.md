# Workstreams

Groups for the "Completed last week" bullets and the per-workstream status in the brief.
Edit freely — rename, merge, reword descriptions; the descriptions decide what goes where.
When new work clearly fits none of these, the brief creates a new group and it's appended here
automatically (marked auto-added), so the same name gets reused from then on.

- Infrastructure — pipelines, CI, monitoring, reliability fixes
- Research — experiments, analyses, prototypes
