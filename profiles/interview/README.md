# Interview profile

Drop your prep material in this folder. Every .md / .txt / .pdf / .docx file here is loaded in
Interview mode (this README is ignored):

- your resume (resume.pdf or resume.docx is fine as-is)
- job.md: paste the job description, company name, and who's interviewing you
- notes.md: things you want to mention, questions you want to ask them, salary expectations

Interview mode also loads profiles/work/all_time.md (your auto-generated work history, including
STAR-format interview stories built from real events), so answers can go beyond the resume.

Tip: before each interview, replace job.md with that company's details.
